# Security policy

## Reporting a vulnerability

Please don't open a public issue for security problems. Report them privately through GitHub:
[Report a vulnerability](https://github.com/maitrios/maitri-pkgs/security/advisories/new).

Include what you found, how to reproduce it, and which version or commit you tested. I'll acknowledge the report as soon as I can and keep you posted on the fix.

## Supported versions

Only the packages currently published on the `stable` and `edge` channels get security fixes.

## Scope

This covers the PKGBUILDs, the build and publish workflows, and the signing setup here. A vulnerability in an upstream project that we package should be reported to that project; if you want a patched version here faster, open an issue after reporting it.
